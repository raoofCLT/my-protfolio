# Abdul Raoof — Developer Portfolio

Personal developer portfolio built with React 18, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## ⚡ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Shadcn UI
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/raoofCLT/my-protfolio.git

# Navigate to project folder
cd my-protfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
