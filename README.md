# Abdul Raoof — Developer Portfolio 🚀

High-performance, modern developer portfolio showcasing full-stack web applications, enterprise systems (ERP/CRM), interactive UI experiences, and technical capabilities. Built with a dark glassmorphism aesthetic, responsive design, and smooth animations.

---

## 🛠️ Tech Stack

- **Framework & Language**: React 18, TypeScript, Vite
- **Styling & UI**: Tailwind CSS, Shadcn UI, Framer Motion, Lucide Icons
- **State Management & Data**: Zustand, Redux Toolkit, React Query
- **Deployment & Tooling**: Vercel, Git, npm

---

## 🚀 Features

- 💼 **Project Gallery & Dynamic Filtering**: Instant tab-based filtering across LMS, CRM, E-commerce, and Web Portals.
- 📱 **Mobile-First Responsive Layout**: Optimized UI layout with custom touch-scroll navigation and zero horizontal overflow.
- ⚡ **Real-Time Interactive Elements**: Animated marquee ticker, dynamic metrics, and modern glassmorphism cards.
- 🛠️ **Categorized Technical Toolkit**: Structured overview of Languages, Frontend, Backend & Database, and DevOps tools.
- 📬 **EmailJS Contact Integration**: Direct messaging form with real-time feedback and social profile links.

---

## 💻 Local Development Setup

Follow these steps to run the application locally:

```bash
# 1. Clone the repository
git clone https://github.com/raoofCLT/my-protfolio.git

# 2. Navigate to the project directory
cd my-protfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

The application will be available at `http://localhost:5173`.

---

## 📦 Build & Production Deployment

To generate a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
